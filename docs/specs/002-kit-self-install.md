# 002. Кит работает по своим правилам

Статус: сделана 2026-10-24
Задачи: T5.7 [x]
Решения: К12

## Зачем

В проектах, куда поставлен кит, агент работает по правилам ядра и с его навыками. В самом ките их нет.
`AGENTS.md` кита — короткая выжимка без таблицы навыков. Сторонние навыки (`ru-text`, `no-ai-slop`,
`test-driven-development`, `verification-before-completion` и другие) в репозитории кита не
установлены. Поэтому документы и навыки кита пишутся без тех правил, которые кит раздаёт проектам.
Запрос пользователя от 2026-10-24.

## Что меняется

Кит ставит в себя своё ядро без профилей: `./install.sh .` в корне кита (решение К12).

- В `AGENTS.md` кита появляется управляемый блок ядра: правила, таблица «ситуация → навык», пункты
  ревью. Выше блока — раздел проекта на русском: журнал решений, команда полной проверки, правила
  самого кита и его отступления от ядра. Правила, которые уже есть в блоке, из этого раздела убираются.
- Отступление от ядра — язык (К5): тексты для агента (`SKILL.md`, `rules.md`, `skills.md`,
  `review.md`, команды) пишутся на английском, а не на русском.
- Навыки ядра ставятся в `.agents/skills/`, симлинки — в `.claude/skills/`, команды OpenCode — в
  `.opencode/commands/`. Шаблоны `TASKS.md` и `docs/specs/README.md` уже есть, установщик их не трогает.
- `.agent-kit.lock` кита не коммитится: в нём коммит самого кита, и он менялся бы с каждым коммитом.
- После изменения `core/` — повторный `./install.sh .`. Тест сверяет блок `AGENTS.md` кита с тем, что
  собрал бы установщик, и падает, если блок устарел.
- Тесты копируют кит без установленных навыков (`.agents/`, `.claude/`).

## Что не меняется

- Ядро, профили и установщик. Правила, которых нет в ядре, сюда не переносятся.
- Профили в кит не ставятся: кит не Helm-чарт, не экспортер и не дашборд.

## Затронутые документы

`AGENTS.md`, `README.md` (раздел «Разработка кита»), `docs/00-overview.md` (раздел 4, К12),
`docs/specs/README.md` (ссылка на правило), `.gitignore`.

## Готово, когда

- `./install.sh .` с сетью — exit 0; в `.agents/skills/` есть `change-workflow` и 6 сторонних навыков
  ядра, в `.claude/skills/` — симлинки на них.
- Повторный `./install.sh .` — `git status` чистый.
- `uv run pytest` проходит и содержит тест на актуальность блока `AGENTS.md` кита; ruff чистый.
