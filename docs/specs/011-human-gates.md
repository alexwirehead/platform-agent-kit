# 011. Две остановки для человека в `change-workflow`

Статус: принята 2026-11-18, пользователь
Задачи: T1.7 [ ]
Решения: К21

## Зачем

Пользователь (2026-11-18): в порядке изменения нужен human in the loop. Сейчас «согласовано с
пользователем — `принята`» решает сам агент: после интервью он ставит статус и идёт в код. Слабая модель
так проскакивает спеку, а коммит появляется без того, чтобы человек видел изменение целиком.

Как делают другие: Kiro и GitHub Spec Kit останавливаются для явного одобрения между артефактами
(требования → план → задачи); быстрые режимы без остановок — для мелочей. Механические права агента
(Claude Code `permissions.ask`/`deny`, OpenCode `permissions`) умеют только действия, не смысл
(«спека одобрена»), поэтому пока не берём (решение пользователя).

## Что меняется

`change-workflow`, две обязательные остановки, обе — инструментом вопроса (Claude Code
`AskUserQuestion`, OpenCode `question`), ход заканчивается вопросом:

1. **Спека.** Агент пишет спеку в статусе `черновик`, показывает выжимку («Что меняется», «Готово,
   когда») и спрашивает: принять или правки. Статус `принята ГГГГ-ММ-ДД, пользователь` пишется сразу
   после явного «да» пользователя на этот вопрос. До этого ни задачи, ни теста, ни кода. Ответы на
   интервью — не одобрение спеки.
2. **Коммит.** Перед каждым коммитом агент показывает `git diff --stat`, сообщение коммита и результат
   полной проверки и спрашивает, коммитить ли.

Работа без спеки (исправление под описанное поведение, рефакторинг, опечатки, документы) — только
остановка 2.

После сжатия контекста правда — файл: спека в `черновик` значит спросить снова, даже если сводка
сжатия говорит об одобрении.

`core/rules.md`, правило 7 — одна строка об обеих остановках: блок `AGENTS.md` переживает сжатие (К17).

## Что не меняется

- Механических прав (`.claude/settings.json`, `opencode.jsonc`) кит не ставит — вернёмся, если текст
  не удержит GLM.
- Остановки после падающего теста нет.
- MR и мерж — по спеке 010.

## Затронутые документы

- `core/skills/change-workflow/SKILL.md` — разделы 1, 4, 5.
- `core/rules.md` — правило 7; блок `AGENTS.md` кита (`./install.sh .`).
- `core/templates/docs/specs/README.md` и `docs/specs/README.md` — статус «принята» с датой и кем.
- `docs/00-overview.md` — К21.

## Готово, когда

- Тест: в правиле 7 и в навыке обе остановки; в навыке — что статус ставится только после «да» и что
  файл важнее сводки сжатия.
- `uv run pytest && uv run ruff check && uv run ruff format --check` чистые.
- Пользователь проверил на GLM: агент останавливается после черновика спеки и перед коммитом, в том
  числе после сжатия.
