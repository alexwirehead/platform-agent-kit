# 009. Агент замечает, что кит не установлен

Статус: принята
Задачи: T5.11 [ ]
Решения: К19

## Зачем

Пользователь (2026-11-18): навыки ставятся локально и в git проекта не попадают, это правильно. Но
инженер, который клонировал проект без кита, получает `AGENTS.md` с таблицей навыков, которых на диске
нет. Агент молча работает без порядка изменения и соглашений профилей, а слабая модель может выдумать
навык по названию. Никто не узнаёт, что кита нет.

В `.agent-kit.lock` уже есть профили и коммит кита. Не хватает адреса кита.

## Что меняется

- **`.agent-kit.lock`** — новая строка `source=<адрес>`: `git remote get-url origin` клона кита на
  момент установки, без учётных данных (`https://user:token@host/...` → `https://host/...`). Нет git
  или `origin` — `source=unknown`. Адрес не хранится в исходниках кита (правило кита 6) и меняется сам
  при установке из другого места, например после переезда кита.
- **Блок `AGENTS.md`, «Starting a session»** — первый шаг: если навыка `change-workflow` нет среди
  доступных, кит в этой копии проекта не установлен. Агент останавливается и говорит пользователю:
  кит не установлен, адрес из `source=`, профили из `profiles=` и команду установки. Ставит, только если
  пользователь попросит, по `INSTALL.md`. Без навыков дальше не работает.
- **`INSTALL.md`, шаг 1** — клон по адресу из `source=` lock-файла проекта, если он есть и не
  `unknown`; иначе как сейчас.

## Что не меняется

- Навыки в git проекта не попадают (К3).
- Агент сам кит не ставит без просьбы пользователя.
- Переезд кита в корпоративный GitLab — отдельное решение, пользователь решит позже.

## Затронутые документы

- `core/rules.md` — «Starting a session»; блок `AGENTS.md` кита пересобрать `./install.sh .`.
- `install.sh` — строка `source=` в lock.
- `INSTALL.md` — шаг 1.
- `README.md` — таблица «что куда ставится» (lock: адрес кита).
- `docs/00-overview.md` — К19.

## Готово, когда

- Тест: кит с `origin` `https://user:secret@example.com/kit.git` пишет в lock
  `source=https://example.com/kit.git`, без `secret`; кит без git — `source=unknown`.
- Тест: блок `AGENTS.md` содержит проверку на `change-workflow` и ссылку на `source=`.
- `uv run pytest && uv run ruff check && uv run ruff format --check` чистые.
- Пользователь проверил: проект с lock без установленных навыков, агент останавливается и подсказывает.
