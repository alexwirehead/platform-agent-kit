# Профиль backstage

Frontend- и backend-плагины Backstage, которые работают через API проекта.

- Навыки из монорепозитория Backstage: `frontend-plugin-development` (новая frontend-система: пакеты,
  подключение в приложение, вкладки сущностей, дев-приложение, тесты, отладка) и
  `backend-plugin-development` (тесты backend-плагинов и модулей).
- Систему плагинов агент определяет по коду; новый плагин в приложении на старой системе — вопрос.
- Логики инфраструктуры в Backstage нет: плагин вызывает API, API запускает Temporal; стандартные
  шаблоны scaffolder для этого не используются. Клиент API генерируется из OpenAPI.
- Проверки: `yarn tsc`, `yarn lint`, `yarn test`; дев-приложение в браузере смотрит человек.
- Пункты ревью: инфраструктура только через API, сгенерированный клиент, система плагинов.

Установка дольше обычной: навыки берутся из большого монорепозитория (около минуты на навык).
