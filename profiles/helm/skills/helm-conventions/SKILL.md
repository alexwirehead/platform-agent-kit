# Team rules for Helm charts

Mandatory for every chart. Template syntax and Helm functions come from the official docs
(`source-driven-development`), general practices from `helm-chart-scaffolding`. Where a rule here and
a general practice disagree, the rule here wins. A project may deviate only by recording it in its
`AGENTS.md`.

## Layout

```text
<chart>/
  Chart.yaml            apiVersion v2, semver; version is bumped on every chart change
  values.yaml           every value annotated (below)
  values.schema.json    generated, never edited by hand
  README.md.gotmpl      README template
  README.md             generated by helm-docs, never edited by hand
  .helmignore           repository files stay out of the package
  templates/            _helpers.tpl, NOTES.txt, objects
  scripts/              scripts that go into a ConfigMap
  tools/                scripts for whoever installs the chart (for example, building values with
                        secrets); packaged, never deployed to the cluster
  ci/                   values sets for checks, named *-values.yaml
```

Repository root: `.pre-commit-config.yaml`, `Makefile` (targets `package`, `push`), `.env.example`,
CI config, `.gitignore` (`*.tgz`, `.env`, `Chart.lock`, `values.local.yaml`, `*-local.yaml`).

The chart version is bumped on every change: the chart repository forbids overwriting a version.

## values.yaml

Every key, nested ones included, is documented for helm-docs. Descriptions are in Russian:

```yaml
# -- Образ контейнера
# @section -- Основные параметры
image:
  # -- Registry образа
  # @section -- Основные параметры
  repository: cr.example/app
```

- `# -- <description>` — description in the README table; an example value goes on extra `# --` lines.
- `# @section -- <Section>` — table section: «Основные параметры», «Безопасность», a section for the main
  object (for example «Deployment»).
- `# @ignored` — key is left out of the README; mandatory for secrets.
- Required value — `# @schema required` (the `helm schema` plugin, losisin/helm-values-schema-json).
  A key with a default in `values.yaml` (`{}`, `[]`) always satisfies `required`: non-emptiness is
  set by `# @schema minProperties: 1` or `# @schema minItems: 1` at the end of the key line. Helm then
  rejects an empty value by the schema, and no `fail` in a template is needed for it.
- `nameOverride` and `fullnameOverride` exist, section «Основные параметры».

## Generated docs

- helm-docs builds `README.md` from `README.md.gotmpl`: `{{ template "chart.header" . }}` at the top,
  `{{ template "chart.valuesTable" . }}` at the end.
- Sections of `README.md.gotmpl`: «Требования», «Описание», «Как это работает», «Ограничения» (if any),
  «Использование» («Установка», «Пример values»), «Сборка и публикация» (`make package`, `make push`,
  table of `.env` variables), «Troubleshooting» (`kubectl` commands).
- `helm schema` builds `values.schema.json` from `values.yaml` and its `@schema` annotations.
- Both files are refreshed by pre-commit hooks (`helm-docs`, `helm-schema`) together with `helmlint`,
  `end-of-file-fixer`, `trailing-whitespace`. Before a commit: `pre-commit run --all-files`.

## Templates

- `_helpers.tpl`: `<chart>.name` and `<chart>.fullname` honouring `nameOverride`/`fullnameOverride`,
  `<chart>.chart`, `<chart>.labels`, `<chart>.selectorLabels` (`app.kubernetes.io/*` labels).
- Every namespaced object has an explicit `namespace: {{ .Release.Namespace }}` and labels from the
  helper.
- An optional object sits under `<key>.enabled`.
- A script lives in `scripts/` and goes into a ConfigMap via `tpl (.Files.Get "scripts/<name>") .`.

## Secrets

The chart creates the Secret itself; there are no references to pre-made Secrets (`existingSecret`).
Values are given in plain text in values, the template encodes them (`b64enc`). The secret key is
marked `# @ignored`.

The chart supports both delivery methods with one template:

1. **SOPS.** The values file with secrets is SOPS-encrypted and never lies in git in plain text;
   Argo CD or Flux decrypt it on deploy. Values hold the value itself.
   Names: `*.enc.yaml` — encrypted file (`.sops.yaml` rule `path_regex: \.enc\.yaml$`),
   `*.dec.yaml` — decrypted or not yet encrypted, local only, in `.gitignore`.
   No other suffixes (`.sops.yaml`, `-local.yaml`, `.secret.yaml`).
2. **Vault via the bank-vaults webhook (target).** Values hold a reference
   `vault:secret/data/<path>#<key>`, the Secret gets `vault.security.banzaicloud.io/*` annotations
   from values (`vault-addr`, `vault-role`, `vault-path` and so on). The webhook injects the value from
   Vault when the Secret is created. Annotations come from values as a map; the chart does not know
   them by name.

## NetworkPolicy

Only for containers that must be privileged (`privileged`, `hostNetwork`, `hostPID`, `hostPath`):
deny-all NetworkPolicy, enabled by default, section «Безопасность». An unprivileged container needs no
NetworkPolicy in the chart.

Unprivileged container: `runAsNonRoot`, `readOnlyRootFilesystem`, `allowPrivilegeEscalation: false`,
`capabilities.drop: [ALL]`, `seccompProfile: RuntimeDefault`; `automountServiceAccountToken: false`
unless the Kubernetes API is needed.

## Packaging and publishing

- `make package` — `helm package <chart> --dependency-update`; `make push` — upload the `.tgz` to the
  chart repository with credentials from `.env` (`HELM_REPO_URL`, `HELM_REPO_USER`, `HELM_REPO_PASS`).
  `.env` is in `.gitignore`, git holds `.env.example`.
- CI: chart check in merge requests, publishing after merge to `main`.
- No real repository or host addresses in git: placeholders (`<helm-repo-url>`) and CI variables.
- `.helmignore` excludes repository files: `Makefile`, `.env*`, CI config, `.pre-commit-config.yaml`,
  `README.md.gotmpl`, `ci/`, `*.tgz`.

## Checklist before a commit

- [ ] `version` in `Chart.yaml` is bumped.
- [ ] New values keys have `# --` and `# @section --`, secrets `# @ignored`, required ones `@schema required`.
- [ ] `pre-commit run --all-files` passed; `README.md` and `values.schema.json` were updated by it, not by hand.
- [ ] The chart check passed (`dev/check-chart.sh`).
- [ ] No plain-text secrets and no real addresses in git.
