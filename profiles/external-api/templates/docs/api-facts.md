# Факты API

Единственный источник фактов об API для проекта. Каждый факт сверен с первоисточником, источник указан
рядом. Нужен факт, которого здесь нет, — навык `api-fact-check`. Придумывать нельзя.

Обозначения источников:

- **[spec]** — машиночитаемая спецификация: репозиторий, путь, коммит.
- **[doc]** — страница официальной документации, дата просмотра.
- **[code]** — код клиентской библиотеки, файл и версия из lock-файла.
- **[reg]** — реестр эндпоинтов или другой публичный ответ, дата.
