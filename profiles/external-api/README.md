# Профиль external-api

Работа с внешним API без доступа к самой системе.

- Навык `api-fact-check`: факт об API только из первоисточника (спецификация, документация, код
  библиотеки, реестр) с источником; ненайденное — открытый вопрос и пункт чек-листа приёмки;
  наблюдения отдельно от фактов; фикстуры по факту.
- Правило: агент не вызывает реальную систему и не просит ключи.
- Шаблон `docs/api-facts.md` (если файла нет): разделы фактов, наблюдений, вопросов и приёмки.
