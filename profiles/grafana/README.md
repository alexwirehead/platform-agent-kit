# Профиль grafana

Любой дашборд Grafana, который хранится в репозитории JSON-ом: сервис (RED), инфраструктура (USE),
здоровье экспортера или пайплайна, карта состояния, SLO.

- Навык `grafana-dashboard`: JSON из выгрузки Grafana (формат v2, когда нужны его возможности),
  переменные вместо копий, стратегии RED и USE, `$__rate_interval`, пороги для величин и value mappings
  для категорий, «No data» отдельно от нуля и «Unknown», строка свежести данных, приёмы PromQL, ловушки
  таблиц и раскладки v2, отдельный раздел про карту состояния, проверка на стенде.
- Источники: best practices и справка Prometheus в документации Grafana; ловушки помечены версией,
  на которой проверены (13.2.4).
- Пункты ревью: `${datasource}`, цвета, `$__rate_interval`, единицы.
