# Профиль grafana

Дашборд состояния Grafana, который хранится в репозитории JSON-ом.

- Навык `grafana-dashboard`: формат v2 из выгрузки Grafana, только Stat и Table, цвет через value
  mappings, «Unknown» отдельно от «No data», строка «Сбор данных», ранжирование и join в PromQL,
  ловушки таблиц (`noValue`, вложенные таблицы), проверка на локальном стенде.
- Пункты ревью: цвета, «Сбор данных», `${datasource}`, нет реальных ID.

Обычно ставится вместе с `python-exporter`.
