# Профиль fluxcd-debug

Отладка Flux на живом кластере через MCP-сервер Flux Operator только на чтение; требует `fluxcd`.

- Сторонний навык `gitops-cluster-debug` из `fluxcd/agent-skills`: статус, события и логи ресурсов Flux,
  трассировка нагрузки до источника, предпросмотр изменения на кластере.
- Кластер — только через `flux-operator-mcp serve --read-only`, секреты замаскированы. Сервер настраивает
  пользователь. Агент кластер не меняет, исправление — MR в репозиторий (решение К16).
- Ставится по желанию: при установке агентом агент спрашивает, нужна ли отладка живого кластера.

Нужен: `flux-operator-mcp` 0.60+ и kubeconfig с доступом к кластеру.
