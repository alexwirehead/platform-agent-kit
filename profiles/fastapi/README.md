# Профиль fastapi

API на FastAPI, которое вызывает Backstage и которое запускает workflow Temporal. Требует `python`.

- Официальный навык `fastapi` из репозитория FastAPI: `Annotated`, зависимости, модели ответа,
  роутеры, стриминг. Возможность из навыка сверяется с версией FastAPI в `uv.lock`.
- Отступления: деплой — k8s через чарт проекта, не FastAPI Cloud; советы навыка про SQLModel, Asyncer и
  другие библиотеки и появление БД решает пользователь.
- API — только клиент Temporal, worker в нём не запускается; клиент подменяется в тестах через
  `dependency_overrides`.
- Схема OpenAPI — контракт с Backstage: ломающее изменение согласуется, клиент в Backstage
  перегенерируется.
- Пункты ревью: версия FastAPI, worker вне API, новые библиотеки, изменения OpenAPI.
