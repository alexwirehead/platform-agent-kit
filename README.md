# platform-agent-kit

Набор правил и навыков агентов (Claude Code и OpenCode) для работы платформенного инженера: Helm-чарты,
экспортеры на Python, работа с внешними API и Yandex Cloud, дашборды Grafana. В кит входит только
то, что уже обкатано в работе.

Статус: спецификация v1 принята — `docs/specs/001-kit-v1.md`, план — `TASKS.md`.

## Как устроен

- **Ядро** ставится всегда: общие правила, подход к доработкам (спецификация → задача → тест → код,
  ветки, мерж после проверки), шаблоны `docs/specs/` и `TASKS.md`, команды ревью для OpenCode.
- **Профили** добавляют правила и навыки под вид работы: `helm`, `python-exporter`, `external-api`,
  `yandex-cloud`, `grafana`. Заготовки на будущее: `cicd`, `fluxcd`, `argocd`, `otel`, `monitoring`.
- **Сторонние навыки** не хранятся в ките: в профиле только список ссылок с закреплённым коммитом,
  ставит их установщик.

## Установка в проект (план)

```bash
~/.agents/platform-agent-kit/install.sh <каталог-проекта> helm python-exporter
```

Установщик собирает управляемый блок в `AGENTS.md` проекта, кладёт навыки в `.agents/skills/`
(для Claude Code — симлинки в `.claude/skills/`), команды в `.opencode/commands/`, записывает
версию кита в `.agent-kit.lock`. Правила проекта пишутся в `AGENTS.md` вне блока, повторный
запуск их не трогает.

## Язык
